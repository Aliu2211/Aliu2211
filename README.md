### Featured Projects

**[SafeRoute](https://github.com/Aliu2211/saferoute)**
Real-time road safety incident reporting and dispatch platform built for the Ghana Highway Authority. Serverless AWS backend (Lambda, DynamoDB, API Gateway, Step Functions, Location Service) with a Next.js operator dashboard, Terraform IaC, and OIDC-based GitHub Actions CI/CD.
`AWS Lambda` `DynamoDB` `Step Functions` `Next.js` `Terraform` `GitHub Actions`

**[PayTrack Africa](https://github.com/Aliu2211/paytrack-africa)**
Multi-tenant serverless invoicing SaaS for Ghanaian SMEs, with Gemini-powered AI collections messaging.
`AWS Lambda` `DynamoDB` `Cognito` `Terraform` `Gemini API`

**[event-cloud](https://github.com/Aliu2211/event-cloud)**
Serverless REST API on AWS that replaces Microsoft Forms and Excel for event registration — built for the getINNOtized × Azubi Africa capstone.
`AWS Lambda` `API Gateway` `DynamoDB` `S3` `Cognito` `Terraform`
